# KLTI

[English](README.md) | [Українська](README.uk.md)

**KLTI (Keyboard Layout Tray Icon)** — легка утиліта для системного трея Windows, яка відображає іконку, пов'язану з поточною активною розкладкою клавіатури.

## Мотивація

Стандартний індикатор розкладки клавіатури Windows є текстовим, через що його може бути складно помітити під час практичної роботи, особливо коли встановлено багато розкладок клавіатури.

Візуальний індикатор дозволяє значно легше розпізнати активну розкладку одним поглядом. Однак наперед визначені візуальні символи не завжди є доречними або бажаними. Наприклад, для індикаторів мови та розкладки клавіатури часто використовують прапори країн, але прапор країни не обов'язково представляє саму мову або розкладку.

Тому KLTI використовує іконки, задані користувачем, і не нав'язує жодного конкретного способу візуального представлення. Індикатором може бути прапор країни, інше зображення або навіть просто колір, який легко помітити периферійним зором. Це дозволяє вибрати представлення, яке найкраще відповідає вподобанням або конкретному випадку використання.

## Опис

KLTI визначає активну розкладку клавіатури за її Windows **LANGID** і шукає відповідну іконку в підкаталозі `icons` директорії, що містить виконуваний файл KLTI:

`<KLTI executable directory>/icons`

Наприклад, якщо встановлені розкладки мають такі LANGID:

* `0x0409` — English (United States)
* `0x0422` — Ukrainian
* `0x0804` — Chinese (Simplified, PRC)

KLTI шукає відповідні файли іконок, використовуючи два варіанти іменування.

Основний формат — шістнадцятковий, із рівно чотирма шістнадцятковими цифрами: `0x0409.ico`, `0x0422.ico`, `0x0804.ico`.

Також підтримуються десяткові імена файлів як запасний варіант: `1033.ico`, `1058.ico`, `2052.ico`.

Якщо існують обидва варіанти, перевага надається шістнадцятковому імені.

Спеціальна іконка `unknown.ico` використовується як запасний варіант, якщо для активного LANGID відповідної іконки немає.

Під час запуску KLTI перевіряє наявність іконок для встановлених розкладок і повідомляє про відсутні іконки. Під час роботи, якщо іконку для поточної розкладки не знайдено, використовується `unknown.ico`.

## Збірка

### Вимоги

* Windows
* x64
* C++17
* Visual Studio 2022 Build Tools з MSVC v143
* ImageMagick, доступний як `magick.exe` у `PATH`

Проєкт не потребує сторонніх runtime-бібліотек. Код навмисно мінімально використовує стандартну бібліотеку C++, щоб зменшити розмір виконуваного файлу. Розмір Release-збірки становить приблизно **18 KB**, або приблизно **24 KB із вбудованою іконкою застосунку**.

### Команди збірки

Для звичайної збірки:

```text
build.bat Res
build.bat
```

`Res` генерує необхідні `*.ico` файли й має бути виконаний перед збіркою Debug або Release.

`build.bat Res`
: Генерує `*.ico` файли. **Потрібно виконати** перед збіркою Debug або Release.

`build.bat`
: Збирає Release-версію та заповнює `dist/Release`.

`build.bat Debug`
: Збирає Debug-версію.

### Іконки та ресурси

Вихідні SVG-файли, з яких створюються іконки, **не публікуються в цьому репозиторії**.

Вихідні ресурси мають знаходитися в таких місцях:

```text
assets/
  klti.svg
  unknown.svg
  layout-icons/
    0x0409.svg
    ...
```

Імена файлів іконок розкладок відповідають Windows LANGID. Наприклад, `0x0409.svg` використовується для створення іконки для LANGID `0x0409`.

`build.bat Res` генерує:

* іконки розкладок із `assets/layout-icons/*.svg` у `dist/Release/icons/`;
* `unknown.ico` з `assets/unknown.svg` у `dist/Release/icons/`;
* `klti.ico` з `assets/klti.svg` у `build/resources/`.

Файл `klti.ico` вбудовується у виконуваний файл застосунку. Інші ICO-файли є runtime-ресурсами й завантажуються з директорії `icons` поруч із виконуваним файлом.

Репозиторій **не містить** SVG-графіку, необхідну для генерації цих ресурсів. Зокрема, навмисно не включені:

* вихідний SVG для іконки застосунку (**потрібен для збірки**);
* вихідний SVG для `unknown.ico` (**потрібен для запуску**);
* SVG-файли іконок розкладок клавіатури (**потрібні для повноцінного запуску**).

Для компіляції потрібна іконка застосунку, а для повноцінної роботи — повний набір іконок розкладок. Тому перед виконанням `build.bat Res` користувач має самостійно надати або створити необхідні SVG-ресурси.
